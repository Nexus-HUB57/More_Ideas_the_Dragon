# Correção de escopo da versão v1

A versão v1 foi publicada antes da reconciliação final do recurso de créditos e permanece preservada exatamente como foi comitada. A implementação de **40.000 créditos/mês**, incluindo schema, histórico, endpoints tRPC e tela `/credits`, está na versão v2 em `imports/orquestrador-trinuclear-web-20260822-v2`.

Esta correção evita substituir ou reescrever arquivos da v1. Para revisão humana, use o pacote v2 e seu manifesto/ZIP correspondentes.
