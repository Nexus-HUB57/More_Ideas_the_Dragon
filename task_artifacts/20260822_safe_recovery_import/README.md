## Política de segurança

Chaves privadas, seeds, senhas, tokens, backups de carteira, listas de credenciais e dados equivalentes não serão copiados para o repositório, nem usados por workflows. O inventário registra somente nome, tamanho, classificação e SHA-256.

Este pacote não executa recuperação por força bruta, assinatura, movimentação de fundos ou broadcast. Qualquer operação legítima deve usar somente credenciais fornecidas explicitamente pelo proprietário e exigir revisão humana.
