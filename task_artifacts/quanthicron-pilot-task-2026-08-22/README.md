# Pacote de arquivos — Quanthicron / Episódio Piloto

Este diretório foi adicionado em uma área exclusiva e não destrutiva do repositório compartilhado. Ele reúne os arquivos fornecidos nesta tarefa e eventuais artefatos de trabalho locais encontrados no workspace.

A importação foi feita sem alterar, remover ou substituir arquivos fora desta pasta. Arquivos potencialmente sensíveis foram deliberadamente excluídos da importação.

O manifesto `MANIFEST.sha256` registra o hash SHA-256 de cada arquivo-fonte. O ZIP end-to-end foi criado a partir desta área e possui seu próprio hash em `PACKAGE.sha256`.
Quantidade de arquivos-fonte importados: **60**.
