# Identidade visual SNF — Seed Need Feed

Esta coleção reúne os artefatos visuais produzidos nesta tarefa para o projeto **Seed Need Feed**, orientado a startups e à metodologia **SNF E²**, com o slogan **“Ideias Exponenciais. Soluções 4 All.”**.

## Escopo

A pasta `assets/` contém as provas e versões geradas durante a exploração visual: propostas iniciais, variações futuristas, a versão com dois `D` espelhados formando um círculo e as provas finais de cor e textura. Os arquivos foram copiados para uma área nova e exclusiva, sem substituir arquivos existentes.

O conjunto contém **24 imagens PNG**. O arquivo `MANIFEST.sha256` registra o hash SHA-256 de cada artefato, e `manifest.json` consolida metadados de inventário. O pacote `snf_brand_identity_2026-08-22.zip` é uma cópia compactada do conteúdo desta coleção.

## Convenção de preservação

Esta entrega foi preparada de forma exclusivamente aditiva. Não foram removidos, renomeados ou sobrescritos arquivos, pastas ou commits preexistentes. Nenhum arquivo de credencial, token, segredo ou configuração privada foi copiado para esta coleção.

Os nomes dos arquivos preservam a sequência de produção para facilitar rastreabilidade. A imagem `snf_logo_final_com_slogan.png` representa a versão final criada antes das provas de variação; as demais imagens representam propostas e estudos visuais.

## Validação

Para validar a coleção localmente, execute:

```bash
./validate_snf_bundle.sh
```

A validação verifica a quantidade esperada de imagens, a existência dos metadados, a consistência dos hashes e a presença do ZIP.
