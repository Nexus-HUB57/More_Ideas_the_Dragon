# Pacote de Análise Financeira — Ano 4 e Ano 5

Este pacote reúne os documentos-fonte fornecidos pelo usuário, relatórios analíticos, plano de ação, dados intermediários e script de cálculo desta tarefa.

O conteúdo foi importado em caminho exclusivo e não destrutivo. Nenhum arquivo, pasta, branch ou commit existente foi removido ou substituído.

## Estrutura

- `source_documents/`: documentos DOCX fornecidos.
- `deliverables/`: análises, balanço projetado, comparação e governança.
- `intermediate_data/`: dados, tabelas e plano de ação.
- `scripts/`: script de cálculo comparativo.
- `validation/`: manifestos, hashes e relatório de validação.

Os valores são projeções e análises internas. A anomalia de R$ 123.738.329,01 e as demais premissas devem ser confirmadas por contador ou auditor independente antes de qualquer decisão contábil, financeira ou societária.
