# Entrega segura — análise financeira do Legado Lucas

Esta pasta contém os artefatos produzidos nesta tarefa de análise dos planejamentos estratégicos em Word, abrangendo os Anos 0 a 10.

A entrega foi adicionada em uma área isolada e nova do repositório. Nenhum arquivo existente foi substituído ou removido, e nenhum commit anterior foi reescrito. O arquivo `source_upload/LegadoLucas(1)` é o anexo original preservado byte a byte; seu conteúdo também está disponível em `source_upload/embedded_word_documents/` para inspeção individual.

Os scripts em `analysis_scripts/` documentam as etapas de extração e estruturação. O relatório está em `reports/`. Os checksums e os resultados de validação estão em `validation/`.
