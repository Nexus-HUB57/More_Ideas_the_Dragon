# Pacote Seguro — Tarefa Legado Lucas

Este diretório contém os artefatos disponíveis desta tarefa, organizados sem alteração ou remoção de arquivos preexistentes do repositório. A população foi realizada em um caminho exclusivo para reduzir o risco de colisão com contribuições de outros desenvolvedores.

## Conteúdo

| Diretório | Conteúdo |
|---|---|
| `source_archive/` | Arquivos ZIP originais recebidos na tarefa. |
| `source_documents/` | Documentos `.docx` extraídos do arquivo original, preservados como fonte. |
| `generated_markdown/` | Relatórios anuais gerados anteriormente em Markdown, anos 0 a 10. |
| `financial_models/` | Scripts Python utilizados nas modelagens financeiras. |
| `deliverables/` | Pacote ZIP de relatórios e PDF de balanços produzidos anteriormente. |

## Protocolo de preservação

Os arquivos foram adicionados em uma branch dedicada, sem `reset --hard`, `rebase`, remoção de arquivos, alteração de commits existentes ou sobrescrita de caminhos fora deste diretório. O branch-base foi preservado e o conteúdo novo está isolado para revisão e integração posterior.

## Observação de integridade

A presença dos artefatos neste pacote não constitui validação contábil independente. Os relatórios e modelos devem ser revisados por profissional habilitado antes de uso financeiro, jurídico, tributário ou institucional. O inventário e os hashes do pacote encontram-se no arquivo `MANIFEST.sha256`.
