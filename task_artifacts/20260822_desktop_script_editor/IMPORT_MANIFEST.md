# Safe import — Nexus Desktop Script Editor

Esta pasta contém uma cópia isolada dos artefatos produzidos para o aplicativo desktop de visualização e edição de roteiros. Nenhum caminho preexistente foi alterado ou removido.

- `desktop_app/`: código-fonte do aplicativo Electron/React e configuração de build.
- `source_upload/DesenvolvimentodoFrontendparaVisualizareEditarRoteiros.zip`: upload original.
- `source_upload/extracted/`: conteúdo extraído do upload original.
- `archives/nexus_desktop_final.zip`: snapshot final do aplicativo, rastreado por Git LFS.

A validação de integridade está em `VALIDATION_REPORT.md`.
