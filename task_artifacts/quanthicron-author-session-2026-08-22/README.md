# Quanthicron — Pacote de Artefatos da Sessão de Coautoria

Este pacote contém uma cópia isolada dos artefatos produzidos ou fornecidos diretamente nesta sessão de desenvolvimento da série **Quanthicron**. Ele foi criado sem sobrescrever, excluir ou mover arquivos existentes do repositório.

A operação foi feita em uma branch dedicada. Os arquivos desta sessão permanecem em `source_files/`, com nomes preservados. O pacote não inclui arquivos de auditoria interna do ambiente nem arquivos que possam conter credenciais ou segredos.

A referência ao acervo Quanthicron já existente no repositório permanece preservada em `quanthicron/` e em `task_artifacts/quanthicron-pilot-task-2026-08-22/`; este pacote é complementar, não substitutivo.
