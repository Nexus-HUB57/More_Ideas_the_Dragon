# MMN IA / Ebooks — Safe Recovery Import

Este diretório contém os artefatos disponíveis da tarefa de revisão e otimização dos ebooks e capas da operação MMN AI-to-AI, importados de forma não destrutiva em 22 de agosto de 2026.

O pacote foi colocado em um caminho novo para evitar sobrescrever ou excluir qualquer arquivo, pasta ou commit existente. O inventário completo está em `MANIFEST.paths`, e a integridade dos arquivos está registrada em `MANIFEST.sha256`.

A pasta `artifacts/` contém os prompts de capas, relatórios, diretrizes e scripts de transformação/revisão. A pasta `source_snapshot/` contém o snapshot local recuperado dos documentos disponíveis nesta sessão.
