# Beyour Bank / Legado Lucas — Pacote End-to-End

Este pacote reúne os artefatos produzidos nesta tarefa sobre o Beyour Bank, o fechamento patrimonial do Ano 3, as projeções do Ano 4 e o Fundo de Participação Societária (FPS).

A importação foi feita em diretório isolado, sem sobrescrever ou excluir arquivos existentes do repositório. O documento DOCX é a fonte fornecida pelo usuário; os arquivos Markdown são relatórios e projeções produzidos durante a tarefa.

## Conteúdo

- `source_documents/`: documento financeiro de origem.
- `reports/`: análises, planos, projeções e comparativos.
- `manifests/`: manifesto SHA-256 para validação de integridade.
