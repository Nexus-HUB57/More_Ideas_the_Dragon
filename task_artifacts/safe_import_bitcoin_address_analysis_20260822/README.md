# Safe import — Bitcoin address analysis (2026-08-22)

Este pacote foi criado em uma área isolada do repositório para preservar o trabalho de outros desenvolvedores. Ele contém somente metadados públicos fornecidos no arquivo `pasted_content.txt`.

## Conteúdo

| Arquivo | Finalidade |
|---|---|
| `addresses.csv` | Registros normalizados para análise tabular |
| `addresses.json` | Registros normalizados em JSON |
| `summary.json` | Contagem, hash de procedência e controles de segurança |
| `README.md` | Escopo e limitações deste import seguro |

## Escopo de segurança

Nenhuma chave privada, seed, mnemonic, credencial, token, assinatura, script de brute force, mecanismo de recuperação, transação ou ação na mainnet foi incluída. O pacote não afirma posse de fundos nem valida saldos; os valores são apenas os dados fornecidos na fonte.

## Procedência

- Fonte: `pasted_content.txt`
- SHA-256 da fonte: `c5b504ae3f039917b5deb2f3d6d33d1ac066d23bd3ee24a1b41185e50f2e68b6`
- Registros parseados: `69`
- Registros com candidato de endereço: `68`

A validação adicional deve usar fontes públicas e autorização explícita; este import é apenas documental e não executa operações financeiras.
