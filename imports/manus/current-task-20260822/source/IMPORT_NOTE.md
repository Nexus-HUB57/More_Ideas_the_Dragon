# Importação segura da tarefa atual

Este diretório foi criado em uma branch isolada para preservar os artefatos disponíveis nesta sessão sem alterar caminhos existentes do repositório. O arquivo de chaves privadas foi incluído somente em forma redigida; o material bruto não deve ser versionado.

A importação é aditiva e não destrutiva. Artefatos Bitcoin existentes no repositório permanecem em seus namespaces originais e são referenciados pelo inventário end-to-end gerado nesta branch.
