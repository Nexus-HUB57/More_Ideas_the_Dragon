## Protocolo Safe Recovery

O pacote foi criado em área isolada dentro de `imports/gestao-grandes-fortunas-task-20260822`. Nenhum arquivo, pasta, branch ou commit preexistente foi sobrescrito ou excluído. A operação deve permanecer em branch própria e ser revisada antes de qualquer integração.

## Conteúdo

A pasta `documentos/` reúne os sete documentos Markdown produzidos durante a tarefa. A pasta `fonte/` contém o documento DOCX originalmente fornecido pelo usuário, preservado como fonte de referência.

O número de arquivos deste pacote corresponde aos artefatos efetivamente disponíveis nesta sessão. Não foram fabricados arquivos vazios ou cópias artificiais para atingir uma contagem nominal, pois isso prejudicaria a integridade do ecossistema. A relação completa e os hashes SHA-256 estão em `MANIFESTO_SHA256.txt`.

## Validação

Execute `python3 scripts/validate_package.py` a partir deste diretório para verificar a existência dos arquivos, a contagem registrada e os hashes. O script não altera o conteúdo do pacote.
