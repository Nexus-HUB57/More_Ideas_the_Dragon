# Nexus Genesis Sync — pacote sanitizado

Este diretório contém somente artefatos verificáveis e não confidenciais extraídos de `NexusGenesis.zip`. Nenhum arquivo existente do repositório foi substituído ou excluído. O arquivo `MANIFEST.json` registra cada entrada de origem, SHA-256, destino e motivo de quarentena. Credenciais Firebase, chaves privadas, seeds, carteiras, tokens, `pasted_content.txt` e arquivos que os contêm foram deliberadamente omitidos. O ZIP original permanece fora do repositório.

## Revisão

Compare o manifest com o ZIP de origem antes de aprovar qualquer integração. Os artefatos em `source/` são material de referência; scripts não foram executados automaticamente.
