33	Meta

35	This library provides well-tested Python bindings for libsecp256k1, the heavily optimized C library used by Bitcoin Core for operations on the elliptic curve secp256k1.
36
37	Features¶
38	Fastest available implementation (more than 10x faster than OpenSSL)
39	Clean, easy to use API
40	Frequent updates from the development version of libsecp256k1
41	Linux, macOS, and Windows all have binary packages for multiple architectures
42	Deterministic signatures as specified by RFC 6979
43	Non-malleable signatures (lower-S form) by default
44	Secure, non-malleable ECDH implementation
