# Importação segura — MMN Agentesia

Este pacote foi importado em um namespace isolado para preservar os paths, commits, branches e arquivos já existentes no repositório. A origem principal é `/home/ubuntu/mmn-agentesia`, e o arquivo enviado pelo usuário foi preservado em `source-archives/MMNAgentesia.zip`, com seus entries extraídos em `source-archives/MMNAgentesia-ZIP/`.

O conteúdo do projeto foi copiado sem `.git`, `node_modules`, `dist` e `.manus-logs`, pois são estado local, dependências geradas, artefatos de build ou logs de execução e não devem contaminar o repositório compartilhado. Nenhum caminho preexistente fora deste diretório isolado foi alterado ou removido.

O manifesto `MANIFEST.tsv` contém origem, destino relativo ao pacote, tamanho e SHA-256 de cada arquivo importado. O manifesto `SOURCE_SCOPE.md` registra as contagens e os critérios de validação.
