# Pacote de Tarefa — Ecossistema Autônomo

Este diretório contém uma cópia não destrutiva e versionada dos artefatos recebidos nesta tarefa. `source_zips/` contém os ZIPs originais; `extracted/outer/` contém o primeiro ZIP; `extracted/nested_1/` contém o ZIP intermediário extraído; e `extracted/nested_2/` contém o pacote final extraído separadamente.

A separação por camadas preserva versões com nomes iguais sem sobrescrição. Nenhum arquivo, pasta ou commit preexistente do repositório foi removido ou substituído. O manifesto SHA-256 abaixo registra a integridade dos artefatos incorporados.
