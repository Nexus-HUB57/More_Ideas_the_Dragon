# Contribuição segura — transferência Bitcoin em duas etapas

Este namespace foi criado de forma não destrutiva para consolidar os artefatos disponíveis desta tarefa. Nenhum arquivo ou commit existente foi removido, substituído ou renomeado.

A pasta `source/` contém a implementação review-first e os scripts históricos sanitizados. A pasta `archive/` contém um ZIP end-to-end com duas áreas: os 299 arquivos já existentes em `artifacts/end-to-end/001-299` e os arquivos desta tarefa em `task-source/`. A pasta `validation/` contém os inventários e o checksum do pacote.

Segredos, chaves privadas, senhas, ambientes locais e credenciais não fazem parte desta contribuição. A ausência de qualquer arquivo não disponível fisicamente no sandbox é registrada como limitação, em vez de ser preenchida artificialmente.
