## Protocolo Safe Recovery

Todos os artefatos desta tarefa foram adicionados sob o diretório exclusivo deste pacote. Antes do commit, foram previstas validações de integridade por SHA-256, verificação de colisões, revisão do diff e checagem do estado do working tree.
