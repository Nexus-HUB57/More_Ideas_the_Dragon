# Informações sobre Acesso ao Llama 4 Maverick

## Método de Acesso

O acesso ao Llama 4 Maverick é feito através de um **formulário de solicitação** no site oficial da Meta (llama.com). Este formulário requer:

- Nome completo (primeiro e último nome legal)
- Data de nascimento
- Email
- País/Região
- Organização/Afiliação (nome completo com todos os identificadores corporativos)
- Cargo/Título do trabalho
- Seleção dos modelos desejados

## Especificações do Llama 4 Maverick

- **Tipo:** Modelo multimodal open-source mais poderoso da Meta
- **Parâmetros:** 17B parâmetros ativos x 128 experts, 400B parâmetros totais
- **Arquitetura:** Mixture of Experts (MoE)
- **Capacidades:** Inteligência líder da indústria e respostas rápidas a baixo custo
- **Modalidades:** Texto e Multi-imagem
- **Inclui:** Llama Guard 4 12B, Llama Prompt Guard 2 22M e Llama Prompt Guard 2 86M
- **Licença:** Llama 4 Community License Agreement

## Alternativas para Acesso via API

Como o acesso direto requer aprovação da Meta, existem alternativas para usar o Llama 4 Maverick via API:

1. **OpenRouter** - Oferece acesso gratuito ao Llama 4 Maverick: https://openrouter.ai/meta-llama/llama-4-maverick:free
2. **Oracle Cloud Infrastructure (OCI)** - Serviço de IA Generativa com Llama 4 Maverick
3. **Google Vertex AI** - Llama 4 Maverick 17B-128E disponível como modelo parceiro
4. **Hugging Face** - meta-llama/Llama-4-Maverick-17B-128E-Instruct

## Plano de Implementação

Para este projeto, vamos usar uma das APIs públicas disponíveis (como OpenRouter) para integrar o Llama 4 Maverick ao nosso assistente de codificação, evitando o processo de aprovação que pode levar tempo.
