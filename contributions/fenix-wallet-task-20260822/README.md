# FênixWallet — pacote de contribuição segura

Este diretório contém os artefatos de código e documentação produzidos nesta tarefa, organizados como uma contribuição isolada e aditiva ao repositório. Nenhum arquivo existente do repositório foi substituído ou removido.

O pacote **não inclui arquivos brutos de carteira, seeds, chaves privadas, WIF, xprv ou credenciais**. Esses materiais são segredos operacionais e não devem ser publicados em um repositório Git, mesmo quando ele é privado. Os nomes e o inventário de entrada estão registrados apenas como metadados na documentação de segurança.

## Conteúdo

O backend Flask está em `backend/src/`; a documentação está em `docs/`; os relatórios e manifestos de integridade estão em `validation/`. O arquivo ZIP em `archive/` contém somente estes artefatos não sensíveis.
