# Pacote Financeiro do Legado Lucas Thomaz — Tarefa End-to-End

Este diretório reúne os artefatos efetivamente gerados durante esta tarefa: documentos de projeção, análises financeiras, cálculos de composição patrimonial e os documentos DOCX utilizados como fonte. A importação foi feita em namespace exclusivo para preservar arquivos e commits preexistentes.

## Conteúdo

- `source/`: documentos DOCX de origem, quando disponíveis.
- `reports/`: relatórios e projeções em Markdown.
- `calculations/`: memória de cálculo do Patrimônio Líquido do Ano 7.
- `manifests/`: inventário e hashes SHA-256.

Os valores são projeções e premissas de trabalho, não demonstrações contábeis auditadas.
