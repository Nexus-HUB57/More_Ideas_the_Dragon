# Importação segura — Bot de Arbitragem Bitcoin com FDR

Esta entrega foi adicionada em uma branch isolada e em um namespace novo para preservar integralmente o histórico e a árvore existente do repositório.

O conteúdo inclui o backend Flask, modelos, rotas, dashboard web, scripts operacionais e documentação da tarefa. O pacote `packages/arbitrage_bot_fdr_source_only.zip` é um ZIP end to end apenas com código e documentação não sensíveis.

A aplicação permanece em modo de demonstração até uma auditoria independente das integrações de exchange, autenticação, limites de risco, gestão de segredos e procedimentos de aprovação. Esta importação não executa transações de Bitcoin e não publica chaves privadas, seeds, dumps de carteira ou credenciais.
